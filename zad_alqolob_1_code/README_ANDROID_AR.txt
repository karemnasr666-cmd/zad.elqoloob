زاد القلوب — مشروع الويب وتطبيق أندرويد

مهم:
- ملف index.html هو واجهة التطبيق الأصلية، ويُنسخ إلى أصول Android داخل android/app/src/main/assets/www/.
- تم الاحتفاظ بمحتوى التطبيق وأقسامه الأساسية، وإضافة تحسينات للتنقل والإحصائيات والتذكيرات والتوافق مع الشاشات.
- الأيقونة موجودة داخل موارد Android بمقاسات متعددة.
- اسم التطبيق وحزمة المشروع لم يتغيرا.

بناء APK عبر GitHub Actions:
1. ارفع محتويات الأرشيف مع الحفاظ على المجلدات، بحيث يكون مجلد .github بجوار zad_alqolob_1_code.
2. افتح تبويب Actions في GitHub.
3. اختر Build Zad Al Qolob APK ثم Run workflow.
4. خطوة البناء الأولى تُحضّر بيانات القرآن (114 سورة و6236 آية)، والأربعين النووية (42 حديثًا)، وأول 100 حديث من صحيح البخاري، وتضمّنها داخل APK.
5. بعد نجاح التشغيل، افتح نتيجة التشغيل ونزّل Artifact باسم zad-alqolob-debug-apk.
6. فك ضغط Artifact وثبّت app-debug.apk على هاتف Android.

البناء المحلي:
- يحتاج Android SDK وJDK 17 وGradle 8.9 وPython 3.
- من مجلد zad_alqolob_1_code نفّذ أولًا: python3 scripts/prepare_offline_data.py
- ثم من داخل zad_alqolob_1_code/android نفّذ: gradle assembleDebug
- الناتج: app/build/outputs/apk/debug/app-debug.apk

العمل دون إنترنت:
- التطبيق بعد بناء APK بالـ workflow أعلاه يقرأ القرآن والأحاديث من ملفات محلية داخل assets ولا ينزّل هذه المحتويات عند فتح الأقسام.
- خطوة تجهيز البيانات تحتاج إنترنت وقت بناء APK فقط؛ لا يحتاج المستخدم إلى إنترنت لتنزيل المحتوى بعد التثبيت.
- تبقى أذونات الإنترنت في التطبيق تحسبًا لخدمات Google والمزامنة المستقبلية، لكن لا تستخدم أقسام القرآن والأحاديث مصادر خارجية وقت التشغيل.

مهم قبل اعتبار النسخة نهائية:
- تسجيل Google والمزامنة السحابية غير مكتملين؛ يحتاجان مشروع Google/Firebase ومعرّف OAuth وخادمًا أو قاعدة بيانات آمنة، ولم تكن هذه الإعدادات موجودة في الملفات المستلمة.
- إشعارات Android المحلية تمت إضافة أساسها البرمجي، ويجب اختبار إذن الإشعارات وسلوك التذكير على هاتف فعلي.
- يجب تنفيذ بناء APK واختباره على أكثر من جهاز قبل النشر.
